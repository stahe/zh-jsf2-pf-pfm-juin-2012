    10. 示例应用-06：rdvmedecins-pfm-spring

    10.1. 移植

    现在我们将前一个应用程序移植到 Spring / Tomcat 环境中：

    我们将基于两个已编写的应用程序。我们将使用：

    • 02 版本的 [DAO] 和 [JPA] 层JSF / Spring，
    • 来自 05 版 PFM / EJB 的 [web] / Primefaces mobile 层，
    • Spring 配置文件（版本 02）

    此处我们进行的工作与之前将 JSF2 / EJB / Glassfish 应用程序移植到 JSF2 / Spring Tomcat 环境时类似。因此我们将减少说明。 如有需要，读者可参考该移植案例。

    我们将移植所需的所有项目都放在了一个新的文件夹 [rdvmedecins-pfm-spring] [1] 中：

    • [mv-rdvmedecins-spring-dao-jpa]：02版[DAO]和[JPA]的层，以及JSF / Spring，
    • [mv-rdvmedecins-spring-metier]：02版[métier]的层，JSF / Spring，
    • [mv-rdvmedecins-pfmobile]：05版Primefaces mobile的[web]层 / EJB，
    • 在 [2] 中，我们将它们导入 NetBeans，
    • 在 [3] 中，Web 项目的依赖关系不再正确：
      • 针对 [DAO]、[JPA]、[métier] 层的依赖关系必须修改，使其现在指向 Spring 项目；
      • Glassfish 服务器曾提供 JSF 的库。但在 Tomcat 服务器上已不再提供。因此必须将其添加到依赖项中。

    [web] 项目的变更如下：

    [web] 层中的 [pom.xml] 文件现具有以下依赖项：

    出现了错误。这些错误是由 [web] 层中的 EJB 引用引起的。首先让我们研究一下 [Application] Bean：

    我们移除所有因缺少包而报错的行，将 [IMetier]（这是它在 Spring 层 [métier] 中的名称）重命名为接口 [IMetierLocal]，并使用 Spring 对其进行实例化：

    
package beans;

import java.util.ArrayList;
import java.util.List;
import org.springframework.context.ApplicationContext;
import org.springframework.context.support.ClassPathXmlApplicationContext;
import rdvmedecins.metier.service.IMetier;

public class Application {

  // 业务层
  private IMetier metier;
  // 错误
  private List<Erreur> erreurs = new ArrayList<Erreur>();
  private Boolean erreur = false;

  public Application() {
    try {
      // 实例化 [métier] 层
      ApplicationContext ctx = new ClassPathXmlApplicationContext("spring-config-metier-dao.xml");
      metier = (IMetier) ctx.getBean("metier");
    } catch (Throwable th) {
      // 记录错误
      erreur = true;
      erreurs.add(new Erreur(th.getClass().getName(), th.getMessage()));
      while (th.getCause() != null) {
        th = th.getCause();
        erreurs.add(new Erreur(th.getClass().getName(), th.getMessage()));
      }
      return;
    }
  }

  // 获取器
  public Boolean getErreur() {
    return erreur;
  }

  public List<Erreur> getErreurs() {
    return erreurs;
  }

  public IMetier getMetier() {
    return metier;
  }
}
