## 📘 概述

本项目配套的课程内容包括：

* **JavaServer Faces 2 (JSF2)**
* **PrimeFaces**
* **PrimeFaces Mobile**

目标是开发一个适用于多种技术环境的完整 **日程管理** 应用程序。

本文件刻意采用务实风格：仅介绍实现所研究应用程序所需的必要内容。

---

## 🏗️ 已开发的应用程序

该应用程序在以下环境中开发：

1. *Glassfish 3.1* 上的 **JSF2 / EJB3 / JPA**
2. **JSF2 / PrimeFaces**（支持 Ajax 的版本）
3. **JSF2 / PrimeFaces Mobile**
4. 将各版本移植到 *Tomcat 7* 上的 **JSF2 / Spring / JPA**

➡️ 总计：**六款 Java EE 应用程序**。

---

## 🎯 学习目标

* 理解 JSF2 架构
* 掌握 PrimeFaces 组件的使用
* 集成 JPA 和 EJB3
* 将完整的 Java EE 配置与 Spring / Tomcat 架构进行对比
